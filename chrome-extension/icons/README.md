# Icons für Chrome-Erweiterung

Diese Extension benötigt PNG-Icons in verschiedenen Größen:
- icon16.png (16x16)
- icon32.png (32x32)
- icon48.png (48x48)
- icon128.png (128x128)

## Option 1: SVG in PNG konvertieren

1. Nimm die `icon.svg` Datei
2. Konvertiere sie mit einem Online-Tool (z.B. https://svg2png.com/) in PNG
3. Erstelle die verschiedenen Größen

## Option 2: Eigene Icons erstellen

Erstelle eigene Icons mit:
- Hintergrund: #6200EE (Purple)
- Vordergrund: #FFFFFF (White)
- Symbol: Power-Icon oder ähnliches

## Option 3: Platzhalter verwenden

Falls du keine Icons hast, kannst du temporär einfache farbige Quadrate verwenden.
Die Extension wird trotzdem funktionieren.
